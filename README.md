# Baseem — ניהול חשבונות אישי

אפליקציית ווב אישית (Flask + SQLite) למעקב אחרי הכנסות משכר ומעצמאות, הוצאות
מוכרות לצרכי מס, וחישוב רזרבת מס מומלצת להפרשה מהכנסת העצמאי.

## הרצה מקומית

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# (אופציונלי) הזנת נתוני דוגמה ראשוניים
python seed.py

python app.py
```

האפליקציה תעלה בכתובת http://127.0.0.1:5000 — הנתונים נשמרים בקובץ SQLite
מקומי ב-`instance/finance.db` (לא נכנס ל-git).

## מסכים עיקריים

- **דשבורד** — סיכום חודשי: סה"כ הכנסה, רזרבת מס נדרשת מבוסטון, הוצאות
  מוכרות, פירוט מע"מ, וסיכום שנתי מצטבר. ניתן לדפדף בין חודשים.
- **הכנסות** — רישום תשלומים משני המקורות (בית חולים / בוסטון קליניק / אחר),
  כולל שעות, בונוס וניכוי מס במקור.
- **הוצאות** — רישום הוצאות עם אחוז הכרה לצרכי מס (ביטוח מקצועי, דלק, חומרים
  וכו').
- **הגדרות** — כל הפרמטרים לתכנון (אחוז הפרשה מומלץ, שיעור מע"מ, ביטוח
  לאומי, אחוזי הכרה) ניתנים לעריכה במקום אחד.

## הערה חשובה

כל האחוזים והחישובים באפליקציה הם הערכה לתכנון בלבד, בהתאם לפרמטרים
שהוזנו בהגדרות — הם **אינם ייעוץ מס מחייב**. לחתימה על דוח שנתי (טופס 1301)
ולסוגיות גבוליות יש לפנות לרואה חשבון מוסמך.
